## 门禁（常驻）
- 改码顺序：先写清调用链（页上的钮 → 接口 → 方法）→ 产品书面准 → 再出补丁 → 运维挂上。挂上不算通过；接口通了也不算通过。
- 障缺立刻写短说明交产品裁，禁止闷头出补丁。
- 交接口人核包前：调用链说明 + 库态/界面/按钮三线自测，正例和反例都要有。
- 网页和服务端在云端用 Java 8；安卓补丁默认今晚不开，除非明示。
- 状态机先画完再写码；未达条件按钮置灰，旁注「现在还不能…，请先…」，禁止进页再报错。
- 红线：指定那条冻结样例不动；密钥不进频道、不拷到盒；禁灌库假通。
- 公网是自测环境，写库和登录不再另找负责人点头。打包和写库走云端直达，不经负责人电脑中转（钥由运维管，我不碰）。
- 向负责人汇报一律大白话：说过线/没过/卡在哪/要他定什么。
