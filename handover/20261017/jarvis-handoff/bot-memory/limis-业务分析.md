## ② 项目我怎么理解（总序）

整单正经出报告，业务上要按这条走（产品同向）：

**业务申报 → 合同评审 → 任务 → 采样 → 实验 → 质控（数据审核，不可跳）→ 报告（编制→审核→签发→下载）**

几条钉死口径（今天仍有效）：
- **业务硬门：** 合同评审过了，外采侧能看见「待指派订单」就算业务硬门到任务；不要求任务列表已经生出可采样行。
- **质控不可跳：** 跳过采样/实验数据审核直接办报告链 = 不合格。
- **报告编制前提（Boss 确认 + 我出处同向）：** 编制前必须 **采样数据审核且实验数据审核都通过**，缺一道就该挡（进不了报告工作区）。现网采样没过会挡已有硬刷；**仅实验没过是否一样挡，还要专刷一眼**。
- **「滞控」= 质控室整链**（口语同音）：采样/实验数据审核 → 编制 → 签发/下载；不是新模块。书面没有「滞控」专名。
- **三类模板：** 采样 / 实验 / 报告 怎么配怎么验另有一页；启用保存逐步截图仍有待补。
