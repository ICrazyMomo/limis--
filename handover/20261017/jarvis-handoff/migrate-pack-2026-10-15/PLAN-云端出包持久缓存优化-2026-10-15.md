## 0. 实测根因（样品交接 bc-5dfee62f，不猜）

| 段 | 耗时 | 说明 |
|---|---|---|
| 墙钟 | ~12 分（20:12→20:23 BUILD SUCCESS） | 整次 tip 云端跑 |
| 写码/思考 | ~11 分 | 主耗时（新接口从零写） |
| Maven 单测 | ~9.5 秒 | 指定 3 个测试类 |
| Maven package | ~28 秒 | 含部分阿里云依赖下载（Downloading ~22 次） |
| 命令合计 | ~1 分 | 环境装好后编包本身不慢 |

**结论纠偏：** 「每次从零拉环境」对**依赖冷启动**有部分成立（有下载痕迹），但**今晚这单十几分钟主因是写新代码，不是编译**。缓存方案主要压缩「纯出包/重编」场景（改几行再打 jar）；写新功能仍受模型写码时间约束。


### 交件硬限（2026-10-15 新事实，Jarvis）
- 云端 artifacts **单文件硬限约 100–110MB**。
- 实测：`lei-admin.jar` ~112MB 落盘 → **OSError，文件变 0 字节**。
- 因此「编出 jar」≠「交得上件」；大 jar 必须 **gzip 和/或分片** 再交 artifacts，与 Maven 缓存优化并列。

## 1. 方案要点

### A. 持久缓存（依赖 + 构建产物）
1. **Maven 本地仓持久化：** 云端 VM 将 `~/.m2/repository` 挂到可复用卷（或 Cursor 环境缓存目录）；同仓库后续 tip 只补缺包。
2. **增量编译：** 固定 `mvn -pl lei-admin -am package -DskipTests`（或只跑变更模块测试）；禁止「先全量 test 再带测 package」双跑（本单多浪费 ~10 秒级，习惯上应砍）。
3. **target 复用（可选）：** 同分支连续 tip 保留 `lei-*/target`；改文件后 `-am` 增量；换分支/大合入再 `clean`。
4. **Web：** 若打 dist，`node_modules` 同理持久化；本单样品交接以 Core jar 为主。

### B. 环境变量进镜像（一次配好）
1. 固化 **Temurin JDK8** + **Maven 3.9** 进 Cursor 云端 Environment / 镜像层：`JAVA_HOME`、`PATH`、`MAVEN_OPTS`（如 `-Xmx2g`）。
2. 启动烟测脚本：`java -version` / `mvn -version` 必须打出 1.8；失败即停，禁止边跑边装。
3. 预拉常用依赖（父 POM + lei-system/lei-admin 主依赖）进镜像或首启缓存任务，避免每 tip 冷 Downloading。

### C. 流程门禁（落地后）
- 出包标准命令写进研发门禁：JDK8 证明 + 单次 `package` + sha16 + HANDOFF；禁重复全量测除非产品要求。
- 纯修 bug tip：预期「冷仓首包」与「热仓重包」分开报耗时。


### D. 大 jar 交件（gzip / 分片）— **已强制门禁**
1. **阈值：** 单文件 >100MB（或接近 100MB）禁止原样拷进 `/workspace/artifacts`。
2. **默认：** `gzip -c lei-admin.jar > lei-admin.jar.gz`（或 `pigz`）；HANDOFF 写明原名、原大小、gz 大小、sha256。
3. **过大仍超限：** 按 90MB 分片（`split -b 90m`），HANDOFF 列分片清单与合并命令；运维/下游按清单还原。
4. **核验：** 交件后 `stat` 字节数 >0 且与源一致（或解压/合并后 sha 一致）；0 字节 = FAIL，禁止报交件成功。

## 2. 优化前后耗时预估（出包段，不含写码）

| 场景 | 现状（估） | 优化后（估） | 提速 |
|---|---|---|---|
| 冷仓首次 package（无 ~/.m2） | 1–5 分（视下载） | 镜像预热后仍可能 30–60 秒编译 | 依赖下载接近 0 |
| 热仓增量 package（改少数 Java） | 常被当成「又十几分钟」 | **30–90 秒**量级 | 出包段可压到 1 分钟内 |
| 整次 tip（含写新模块） | 10–20 分 | 写码时间几乎不变；出包段省 1–几分 | **整次未必腰斩**；体感改善在「改完就打」 |

**对 Boss 诚实口径：** 缓存解决「编得慢/装环境慢」；解决不了「从零写 Controller 要想十几分钟」。样品交接类新接口仍会以写码为主。
